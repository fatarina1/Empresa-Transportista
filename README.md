# TPI Microservices (Seguimiento & Logistica)

## Servicios
- `seguimiento-service` (puerto 8081)
- `logistica-service` (puerto 8082)

## Cómo correr
En cada carpeta, ejecutar:
```bash
mvn spring-boot:run
```
Luego abrir Swagger UI:
- Seguimiento: http://localhost:8081/swagger-ui/index.html
- Logistica:   http://localhost:8082/swagger-ui/index.html
